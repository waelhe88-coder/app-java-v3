Authentication Mechanisms
4 login paths • All converge on JWT issuance
Password + MFA
RFC 6238
Two-step login with mfaToken binding (Redis, TTL 5min, single-use).
TOTP: ZXing QR code (Base32 secret per RFC 4648).
Recovery codes: 10 single-use, atomic claim via UPDATE ... WHERE used=false.
TotpService, MfaService, TwoStepLoginService
OAuth2 Social Login
RFC 6749/8252
GitHub + Google OIDC.
PKCE required: require-proof-key=true (RFC 8252 §7.1).
JWT in cookie: HttpOnly + Secure + SameSite=Strict (not URL query).
email_verified: checked via provider API for GitHub (fails closed).
OAuth2LoginSuccessHandler, DevDataInitializer
JWT Resource Server
Spring 7
Decoder: NimbusJwtDecoder with RotatingJWKSource.
Validator: JwtRevocationValidator (checks Redis for revoked jti).
Authority mapper: roles from DB → ROLE_CONSUMER/PROVIDER/ADMIN.
SecurityConfig, JwtRevocationValidator
Brute-Force Protection
OWASP
Atomic counter: UPDATE ... SET failed_attempts = failed_attempts + 1 ... RETURNING.
Threshold: 5 attempts → lock 15min.
DistributedRateLimiter: Redis Lua script (INCR+EXPIRE), fails closed by default.
BruteForceProtectionService, DistributedRateLimiter

Security HTTP Headers (Spring Security 7)
Reference hardening targets — Spring Security 7's built-in defaults (frame-deny, nosniff, referrer policy, HSTS on secure requests) apply to all three chains (order 1-3); the explicit CSP / Permissions-Policy directives below are documented targets, not yet configured in SecurityConfig
HSTS
RFC 6797
Strict-Transport-Security: max-age=31536000; includeSubDomains
Forces HTTPS for 1 year.
.httpStrictTransportSecurity(hsts → hsts.includeSubDomains(true).maxAgeInSeconds(31536000))
CSP
OWASP
default-src 'self'; frame-ancestors 'none'; base-uri 'self'; object-src 'none'
Prevents XSS, clickjacking, MIME sniffing.
.contentSecurityPolicy(csp → csp.policyDirectives("..."))
Permissions-Policy
OWASP
camera=(), microphone=(), geolocation=(), payment=()
Disables sensitive browser APIs.
.permissionsPolicyHeader(p → p.policy("..."))
X-Frame-Options + X-Content-Type-Options + Referrer-Policy
Spring 7
X-Frame-Options: DENY
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
.frameOptions(f → f.deny()).contentTypeOptions(...).referrerPolicy(...)

Key Management & Rotation
NIST SP 800-57 cryptoperiod guidance • single persistent key, manual rotation via runbook (ADR-004 Revised — no automatic rotation)
ImmutableJWKSet (implemented)
NIST 800-57
Single active key — no active+previous overlap (ADR-004 Revised: RotatingJWKSource was never implemented).
Rotation: manual — keytool regeneration + redeploy (runbook: keys/README.md).
Replacing the key invalidates outstanding access tokens (900s); persisted refresh tokens run to their 7-day expiry.
SecurityConfig.jwkSource (marketplace-platform-infra) — ADR-004 Revised
JWT Keystore
Spring
Algorithm: RSA-2048 (asymmetric).
Storage: JKS via $JWT_KEYSTORE_PATH (dev, mounted file) or $JWT_KEYSTORE_B64 (prod — decoded in memory, no file materialized).
Generated via: keytool (runbook: keys/README.md).
MarketplaceProperties.Security.Jwt.KeyStore
Token Revocation
RFC 7009/7662
Revocation list: Redis SET with TTL = JWT remaining lifetime.
Logout: OAuth2AuthorizationService.findById() + remove().
Validator: JwtRevocationValidator checks jti on every request.
SessionController, JwtRevocationValidator

Log Redaction
OWASP
logback-spring.xml: %replace filter strips passwords, tokens, JWTs (eyJ...), BCrypt hashes from all log output (console + file).
CorrelationIdFilter: validates charset (alphanumeric + dash, max 128) to prevent log injection.
logback-spring.xml, CorrelationIdFilter
Trusted Proxy Handling
Spring
server.forward-headers-strategy=framework → ForwardedHeaderFilter resolves X-Forwarded-For from trusted proxy chain.
Rule: trust only request.getRemoteAddr() (resolved), never raw X-Forwarded-For header (spoofable).
application-prod.yml, AuthAuditService.extractIpAddress()
